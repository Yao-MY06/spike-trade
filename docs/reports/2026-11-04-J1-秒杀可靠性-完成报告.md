## 4. 与计划的偏差

1. 新增 `scripts/j1/e2e-smoke.sh`，补测 HTTP 401 与单号贯穿；handoff 要求的 7 个故障场景不变。
2. 测试资源改为 `application-test.yaml` + `@ActiveProfiles("test")`，避免测试配置遮蔽主配置。
3. 既有 ID 并发测试由打印 30,000 行改为断言 30,000 个 ID 唯一，降低证据噪声。
4. 全量测试使用 `mvn clean test`，避免删除测试资源后 `target/test-classes` 残留旧文件。
5. `OutboxService.insertNew` 使用 5 秒事务超时，小于默认 30 秒对账宽限期。
